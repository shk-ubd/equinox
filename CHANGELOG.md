# Changelog

All notable changes to Equinox will be documented in this file.

## [1.0.0] — 2026-08-01

### Added

- **Equinox Dark** — smoked-glass workbench, temperature-coded syntax, semantic highlighting
- **Equinox Light** — warm parchment canvas, high-chroma accents, coral numbers, warm git decorations
- Shared `ThemeTokens` build pipeline (`npm run build`)
- Bracket pair colorization, terminal ANSI, markdown scopes, debug/testing/git chrome
- Preview sample at `src/preview/syntax-sample.ts`
